## 代码与目录清单

| 位置 | 职责与入口 |
| --- | --- |
| [CodeProject/](../CodeProject/) | C/C++ SDK 主程序工程，包含 API 功能库、User 示例和运行配置 |
| [CodeProject/Makefile](../CodeProject/Makefile) | 主构建入口；组织 API 库更新和 API 以外 `.c`/`.cpp` 的自动编译，允许并行，最终链接等待两部分完成 |
| [CodeProject/AheadFormSDK_Config.ini](../CodeProject/AheadFormSDK_Config.ini) | DDS 网卡、外部域、机器人地址和媒体等运行参数，修改后重启生效 |
| [CodeProject/API/](../CodeProject/API/) | 纯 C 的 SDK 功能库，可供客户独立工程调用 |
| [API/subMakefile_buildApiLib](../CodeProject/API/subMakefile_buildApiLib) | 独立 API 静态库构建入口；`api_so` 按需生成动态库，另有编译/链接参数查询目标 |
| [API/AheadForm_Task/Task/](../CodeProject/API/AheadForm_Task/Task/) | SDK 总控制对象、初始化/释放和通用 Reader/Writer 接口 |
| [API/AheadForm_Task/ParseInitConfig/](../CodeProject/API/AheadForm_Task/ParseInitConfig/) | INI 配置读取、字段检查和初始化参数组织 |
| [RobotCtrl/head/](../CodeProject/API/AheadForm_Task/RobotCtrl/head/) | 头部/表情动作发送及动作文件读取 |
| [RobotCtrl/media/](../CodeProject/API/AheadForm_Task/RobotCtrl/media/) | 音频、视频、音量及音频设备等媒体接口 |
| [RobotCtrl/status/](../CodeProject/API/AheadForm_Task/RobotCtrl/status/) | 传感器、颈部和故障池的最新/历史缓存读取 |
| [RobotCtrl/operating_mode/](../CodeProject/API/AheadForm_Task/RobotCtrl/operating_mode/) | 运行模式查询、设置和请求回复处理 |
| [RobotCtrl/emote_play/](../CodeProject/API/AheadForm_Task/RobotCtrl/emote_play/) | 机器人已有资源的播放请求、播放控制和状态事件 |
| [RobotCtrl/topic/](../CodeProject/API/AheadForm_Task/RobotCtrl/topic/) | Topic 数据类型、DDS 消息、发布订阅、Reader/Writer 和异步匹配 |
| [API/common/](../CodeProject/API/common/) | 错误栈、时间、线程、INI、队列及 DDS 等通用支持代码 |
| [CodeProject/User/](../CodeProject/User/) | 可扩展的客户业务示例；包含主入口、终端输入、命令表和客户端剧本播放 |
| [python_demo/](../python_demo/) | 独立 CFFI 编译入口、Python 生命周期管理及 API/User 演示脚本 |
| [python_demo/demo_user.py](../python_demo/demo_user.py) | 原 User 命令表的 Python 菜单入口；无指令时进入 `>>` 连续输入，也支持单次命令和 `--list` |
| [python_demo/bindings.py](../python_demo/bindings.py) | 集中的 CFFI 类型/函数声明；引用原始 C 头文件，不写 C 转发函数 |
| [python_demo/build_bindings.py](../python_demo/build_bindings.py) | 生成 CFFI C 代码、读取本机或目标 Python 配置；实际编译由 Make 完成 |
| [python_demo/requirements.txt](../python_demo/requirements.txt) | Python 接入独立依赖版本，默认部署尝试安装在私有 venv，失败不阻止 C/C++；可显式跳过 |
| [python_demo/doc/](../python_demo/doc/) | Python 接入详细文档 |
| [python_demo/tests/](../python_demo/tests/) | 不连接机器人的替身测试 |
| [deploy/](../deploy/) | 默认 C/C++/Python 部署入口、工具链交互、私有 Python 环境准备、依赖查询和验证测试；`deploy.sh` 为统一入口，`deploy_ubuntu.sh` 为兼容入口 |
| [deploy/deps.mk](../deploy/deps.mk) | 编译器/参数覆盖入口；自动读取部署生成的本地 `.mk` 设置，修改后重新部署，已有旧工具链或旧参数产物时先 clean 再构建 |
| [deploy/python_env.py](../deploy/python_env.py) | 私有 Python 环境创建、CFFI 安装与复用及离线包目录；不构建 SDK 或 Python 扩展 |
| [ThirdParty/](../ThirdParty/) | 已解压 CycloneDDS 源码、来源清单及哈希；不含 GStreamer 源码 |
| [scripts/](../scripts/) | 示例 CSV 剧本及配套音频；播放方法见快速上手 |
| [doc/](./) | SDK 总体使用、配置、架构和剧本等文档及演示材料 |
| `python_demo/.venv/`（生成目录） | 客户私有 Python/CFFI 环境，不随源码提交或跨机器复制 |
| `.deps/`（生成目录） | 部署选择、工具链配置及私有 DDS 缓存，不属于交付源码，不手工修改 |
| `CodeProject/API/` 各源码目录下的 `*.pic.o` 及 API 根目录的 `libAheadFormSDKApi.so`（生成文件） | `make -C CodeProject/API -f subMakefile_buildApiLib api_so` 按需构建的 API 动态库及对象，普通 `make` 不生成 |
| `python_demo/.build/`（生成目录） | 按 DDS 工具链和 Python ABI 隔离的 CFFI 扩展、生成代码、对象及构建信息，本目录 `make clean` 同时删除这些产物并调用 API 子 Makefile 清理标准 API 库及对象文件 |

C/C++ 客户可扩展 User 或其他非 API 目录，也可只链接 API 静态库；Python 客户可只构建 API 接入，或附带 User 业务。两种语言共用现有实现，具体边界见各自接入说明。
